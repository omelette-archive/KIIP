# 법정동코드 데이터

국토교통부가 공개 배포하는 전국 법정동 코드 전체 목록. API 키/가입 없이 다운로드 가능.
출처: `https://www.data.go.kr/data/15063424/fileData.do`
(다운로드 URL: `https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003676587&fileDetailSn=1&insertDataPrcus=N`,
다운로드 2026-08-06).

## 파일

- `법정동코드_전국_20260703.csv` — 원본. 법정동코드/시도명/시군구명/읍면동명/리명/순위/생성일자
  컬럼. 리(里) 단위까지 세분화된 이력 데이터라 20,000행이 넘는다 — 폐지된 옛 코드도 섞여
  있고(폐지일자 컬럼은 없음), `생성일자`만으로는 현재 유효 여부를 판단할 수 없다.

## 용도

`01-collect-specialties/lib/adminCodes.js`가 "시군구명은 있고 읍면동명·리명은 비어있는" 행만
걸러서 시군구 레벨 마스터 목록(269건, 2026-08-06 기준)을 만드는 데 쓴다. 다른 소스(지리적표시,
농사로 등)에서 얻은 지역 문자열을 이 마스터와 대조해 `sido`/`sigungu`로 정규화하는 조인 키로
쓰인다.

⑦ 대시보드 통합 스냅샷은 시도 단위 집계도 있으므로 같은 파일에서 읍면동·리가 비어 있는 시도와
시군구 행을 함께 읽는 `loadAdminRegionCodes()`를 사용한다. 원본에 있는 공식 상위 코드만 사용하며
이름에서 코드를 임의 생성하지 않는다.

269건은 기획 문서가 언급한 "226개 기초지자체"보다 많은데, 원본에 폐지/변경 이력이 섞여 있는
것과 실제 행정구역 개편(신설 시 등)으로 숫자가 계속 바뀌는 것이 원인으로 보인다 — 정확히
226개로 맞추기보다 현재 공식 데이터를 있는 그대로 반영하는 쪽을 택했다.
