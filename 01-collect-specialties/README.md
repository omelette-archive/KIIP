# ① 지역 특산품 데이터 자동 구축

**상태**: 📋 예정 (미착수)

전국 17개 광역 및 226개 기초지자체를 대상으로 특산품 목록을 자동 수집한다.
전체 기획은 [`docs/project-plan.md`](../docs/project-plan.md)의 ① 참고.

## 수집 대상

- 농사로 특산물 정보
- 지리적표시 등록현황
- 지자체 홈페이지
- 뉴스 기사 및 공공데이터

## 할 일

- [ ] 226개 기초지자체 목록(시도/시군구 코드) 기준 데이터 확보
- [ ] 각 수집 대상별 크롤러/API 연동 설계
- [ ] 생성형 AI로 "지역 ↔ 특산품" 관계 자동 추출
- [ ] 통합 DB(지역, 특산품명, 출처, 수집일) 스키마 설계 및 구축

## 출력 (다음 단계 ②의 입력)

지역별 특산품 원시 목록 — 예: `{ sido, sigungu, rawItemName, source, collectedAt }[]`
