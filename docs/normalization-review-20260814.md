## 구현

`02-normalize-items/summarizeReviews.js`가 검토 CSV를 원물명 정규형으로 묶어 다음을 JSON과
CSV로 출력한다.

- 행 빈도와 원본 표현 변형
- 검토 사유
- 관측 지역 수와 출처
- 후보별 출현 행 수·커버리지·평균 점수
- 대표 원본 예시

모든 군집은 `human_review_required`로 유지된다. 승인된 항목만
`02-normalize-items/data/approved-aliases.json`으로 승격한다.

## 다음 승인 묶음 후보

1. 원물과 후보가 동일하고 가공·생물 상태가 바뀌지 않는 항목을 우선 조사한다.
2. `토종꿀 → 꿀`처럼 상위 범주로 합치는 항목은 업무 승인 후에만 추가한다.
3. `멸치`, `바지락`, `붕장어`처럼 생물·비생물 상태에 따라 NICE류가 달라지는 항목은 원천에
   상태 근거가 없으면 검토대기로 유지한다.
4. `양봉`, `과채류`, `전통장류`처럼 품목보다 활동·범주에 가까운 표현은 별도 제외/범주 정책을
   먼저 확정한다.
