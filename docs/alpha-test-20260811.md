## 발견한 문제와 처리

### P0 — 전국 검색 결과를 지역 상표 건수로 사용할 수 없음

같은 `noticeName + niceClass` 검색 결과를 해당 품목이 있는 각 지역행에 복제한다. 출원인 주소가
확인되지 않은 hit까지 지역×품목 상표 건수와 대표성 판정에 들어가므로 모든 지역이 비슷하게 큰
상표 건수를 갖고, 이번 실행에서는 공백 알림이 0개가 됐다.

배포 전 필요한 변경:

1. 전국 품목 검색 결과와 지역 귀속 결과를 별도 fact로 저장한다.
2. 지역 상표 건수에는 주소가 `inside`로 검증된 hit만 사용한다.
3. 주소 커버리지가 임계값 미만이면 지역 건수·공백 점수를 `blocked`로 표시한다.
4. 농사로 지역브랜드 연관성은 출원인 주소 대신 사용할 수 없으므로 계속 별도 지표로 둔다.

후속 코드에서는 전국 검색 건수를 `nationwideSearchTrademarkCount` 참고값으로 분리하고,
지역 건수는 출원인 주소가 `inside`로 확인된 `regionalUniqueTrademarkCount`만 사용하도록
변경했다. 검색 수집 또는 저장 hit의 주소 귀속이 하나라도 불완전하면 지역 건수·등록률·공백
점수를 `blocked` 처리한다. 기존 알파 원본을 API 재호출 없이 다시 계산한 결과 668개 전부가
차단되고 랭킹은 0개가 됐다. 잘못된 수치 노출은 막았지만, 실제 지역 통계를 제공하려면 #50의
주소 보강과 query fact 저장구조 변경이 계속 필요하다.

### P0 — 자동 품목 정규화 커버리지 38.9%

1,049건이 사람 검토 대기다. 현재 규칙만으로 전국 원본을 자동 검색하면 원본의 61.0%가 분석에서
빠진다. 검토대기 사유·빈도를 집계해 반복 패턴부터 규칙으로 승격하고, 애매한 항목만 사람이
확인해야 한다. 사용자 확정 전 AI가 임의로 고시명칭을 결정하지 않는 원칙은 유지한다.

후속 승인으로 파프리카·고추류, 방울토마토, 호박류, 메론, 버섯류 10개 표현 묶음을
`approved-aliases.json`에 기록했다. 고시상품명칭 13판의 대상 명칭·NICE류·유사군코드를 실행 시
다시 확인한 뒤에만 `rule_approved_alias`로 확정한다. 실데이터 재실행에서는 공백 변형 1건을
포함해 90건이 추가 확정되어 커버리지가 44.1%로 올랐다. 한우·벌꿀·단감·잡곡 등 미승인
항목은 계속 검토대기에 남겼다. ③ dry-run에서 검색 가능 행은 669→759로 늘었지만 승인 별칭이
기존 표준명으로 합쳐져 고유 KIPRIS 검색어는 125→126개만 증가했다.

### P0 — 등록원부 429와 보강 지속성

직렬 호출에서도 44건 성공 후 429가 발생했고 남은 56건 재시도로 실행이 약 9분 38초 걸렸다.
계정의 당일 잔여량 또는 제공기관 할당량 소진 가능성이 높다. 이번 수정에서 첫 429 이후 후속
호출을 중단하는 회로 차단과 `selected/requested/rate-limit-skipped` 분리 집계를 추가했다.

추가로 등록번호별 응답 캐시·체크포인트와 일별 호출 예산이 필요하다. 현재 11,608개를 한 번에
보강할 수 없다.

### P1 — ③ 출력 중복과 파일 크기

고유 검색 결과 39,230건이 지역행에 복제되어 233,234건, 검색 결과 175.9MB, 등록원부 보강 결과
189.7MB가 됐다. 검색 결과는 고유 쿼리 단위로 한 번만 저장하고 지역×품목은 query key를 참조하는
구조로 바꿔야 한다.

### P1 — 부분 수집과 월간 호출량

125개 고유 검색에 605페이지를 사용했다. KIPRIS 무료 월 1,000회 범위에서 매번 같은 전체 검색을
반복할 수 없다. 체크포인트를 장기 보존하고 신규·변경 검색만 증분 처리해야 한다. `max_pages=5`를
없애는 것만으로는 월 한도를 초과하므로 해결되지 않는다.

### P1 — 실데이터 교체 시 테스트 fixture 의존

웹 테스트가 영양군 4품목과 특정 exact 사례를 고정 가정해 처음 실패했다. 현재 스냅샷의 실제
지역·랭킹·지정상품 근거 계약을 검사하도록 수정했다.

### 해결 완료 — 지역명 포함관계·광역 단위

`남양주시`가 부분 문자열 `양주시`와 함께 후보가 되는 문제, 부산광역시처럼 시군구 없이 들어오는
광역 단위 원본 문제를 수정했다. 가장 긴 시군구명을 우선하고 광역 단위는 시도 레벨로 보존한다.
재수집 결과 지역 경고는 74건에서 0건으로 줄었다.
