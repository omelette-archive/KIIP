## 주의사항

- 지역별 출원율 분모는 현재 수집된 전체 지역×특산품 항목이며, 미확인 항목도 분모에 포함한다.
- 수집원에서 얻은 품명만으로 지역 특산품으로 단정하지 않는다. 지역 코드 또는 검증 가능한 주소/공식 지역 근거가 필요하다.
- standalone HTML을 변경하면 `07-dashboard/web`에서 `npm test`와 `npm run build:html`을 실행하고 `07-dashboard/dashboard.html`을 함께 커밋한다.
