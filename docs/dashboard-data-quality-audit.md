# 대시보드 데이터 품질 감사

추가 수집 결과를 대시보드에 반영하기 전에 스냅샷의 구조와 표시 경계를 확인한다.

```powershell
node scripts/auditDashboardSnapshot.js
node scripts/auditDashboardSnapshot.js --json
```

`--input <경로>`로 운영 파이프라인이 만든 게시 후보 스냅샷을 직접 검사할 수 있다. 기본 실행은 구조 오류에서만 실패하고, `--strict`는 검토 경고도 실패로 처리한다.

## 표시 경계

- 확인 특산품: `matchingBasis=notice_name_and_nice_class`이고 `noticeName`과 `niceClass`가 모두 있는 행
- 검토 대기: `raw_item_name_unclassified` 등 위 조건을 충족하지 않은 행
- 지도, 특산품 수, 출원율, 상표건수, 랭킹, 지자체 특산품 목록은 확인 특산품만 사용한다.
- 검토 대기 행에 지역 상표 수나 상표 예시가 있어도 확인 특산품으로 승격하지 않는다. 별도 검토 목록에서만 다룬다.
- GI 등록 여부나 상표 출원 건수는 특산품 여부와 별개다. GI 미등록 또는 출원 1건인 품목도 출처와 품목 정규화 근거가 확인되면 포함할 수 있다.

## 현재 스냅샷 기준선

2026-08-19 공개 스냅샷을 감사한 결과는 다음과 같다. 이후 수집으로 수치는 달라질 수 있으므로 고정 통과 조건이 아니라 비교 기준으로 사용한다.

| 항목 | 수치 | 해석 |
|---|---:|---|
| 지역×품목 전체 | 1,692 | 스냅샷에 적재된 모든 행 |
| 확인 특산품 | 803 | 고시명칭·NICE류 확인 |
| 검토 대기 | 889 | 상호·가공품·원물 후보가 함께 있어 별도 검토 필요 |
| 확인 특산품 중 지역 집계 가능 | 28 | 현재 출원율 판정 완료 분모 |
| 검토 대기 중 지역 지표 보유 | 643 | UI가 단순 `available` 합계를 쓰면 혼입되는 위험군 |
| 법정동코드 미해결 지역 | 7 | 지역 귀속 보완 대상 |

고성군의 `꿀다림 데일리허니`, `왕곡한과`는 현재 `raw_item_name_unclassified`로 분류돼 있다. 자동 삭제 대상이라고 단정하지 않고, 특산품 출처·표준 품목·지역 근거를 확인하기 전까지 확인 특산품 화면과 지표에서 제외한다.

## 추가 수집 반영 체크리스트

1. 새 실행의 `snapshotId`, `generatedAt`, 원천 버전과 실행 manifest를 보존한다.
2. 감사 도구로 구조 오류, 검토대기 혼입 위험, 법정동코드 미해결을 확인한다.
3. 확인 특산품 수와 검토대기 수의 증감 사유를 기록한다.
4. `regionalMetricGate.availableRegionItemCount`와 실제 `available` 행 수가 일치하는지 확인한다.
5. 대시보드의 React 화면과 독립 HTML이 같은 필터와 분모를 사용하는지 확인한다.
6. `node scripts/validatePipeline.js`와 `07-dashboard/web`의 테스트를 통과시킨 뒤 게시 후보를 만든다.
