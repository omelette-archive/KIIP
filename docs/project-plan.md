# AI 기반 지역 특산품 브랜드 정책지원 플랫폼 — 프로젝트 기획

출처: `AX 프로젝트.hwpx` (바탕화면 기획안). 저장소의 페이즈(01~07) 구조는 이 문서의 7단계를
그대로 따른다.

## 프로젝트명

**AI 기반 지역 특산품 브랜드 정책지원 플랫폼**

## 추진배경

생성형 AI를 활용한 데이터 수집·정제·분석 자동화 및 지자체 대상 신규 서비스 발굴

## 목표

- 지역 특산품 데이터 자동 수집
- 상표 빅데이터 연계 분석
- AI 기반 비즈니스 확장 전략 제안 자동 생성
- 실시간 대시보드 구축

## 차별성

특허청 상표 빅데이터와 생성형 AI를 결합하여 지역 특산품의 브랜드 활용 수준을 실시간으로
분석하고, 브랜드 공백지역을 자동 도출해 비즈니스 확장 전략을 제안하는 국내 최초 수준의
브랜드 분석 플랫폼 구축.

## 7단계 파이프라인

### ① 지역 특산품 데이터 자동 구축 → [`01-collect-specialties/`](../01-collect-specialties/)

전국 17개 광역 및 226개 기초지자체를 대상으로 특산품 목록 자동 수집.

- 수집 대상: 농사로 특산물 정보, 지리적표시 등록현황, 지자체 홈페이지, 뉴스 기사 및 공공데이터
- 현재 구현은 공식 API가 제공하는 지역-특산품 쌍을 규칙으로 정규화하고 SQLite에 누적한다.
  생성형 AI 추출은 지자체 홈페이지·뉴스 같은 비정형 소스를 실제 범위에 넣을 때만 별도 검토한다.

### ② 규칙 기반 특산품 표준화 및 별도 수동 검토 → [`02-normalize-items/`](../02-normalize-items/)

- 지역명·품종 설명 제거 등 정해진 규칙으로 특산품 명칭을 1차 정제
- 고시명칭이 `원문`, `신선한 원문`, `미가공 원문` 규칙과 일치할 때만 자동 매핑하고
  부분 일치·복수 분류는 검토 대기열로 분리
- 사과나무·사과묘목 등은 명시적 제외 규칙을 적용
- NICE 상품분류(13판) 자동 매핑 — 분석 목적에 맞는 상품류 중심 분류, **35류 이상은 별도 관리**
- 애매한 품목은 중간산출물로 분리하고, 사람이 기존 후보를 승인·제외·보류한 감사 이력을 저장
- 외부 생성형 AI/Claude/Anthropic API는 이 단계의 정규화나 검토 결정에 사용하지 않음

### ③ 지역 특산품 기반 상표정보 자동 수집 → [`03-match-trademarks/`](../03-match-trademarks/)

- 지역명 + 고시명칭 + 품목을 활용하여 상표 Open API 자동 검색
- 상표명뿐 아니라 **지정상품, 상품류, 출원인 주소**를 함께 고려하여 관련 상표 자동 수집
- 신규 출원 정보를 주기적으로 업데이트하여 실시간 데이터베이스 구축

> **현재 상태**: 품목(상품류) 기준 검색·필터는 v1으로 실동작(`03-match-trademarks/`). KIPRIS
> 상표 검색 API 응답에는 출원인 주소가 없지만, 등록번호가 있는 상표는 별도 등록원부
> `getMarkHistory`의 출원인 주소·지정상품으로 소량 보강하는
> 파이프라인을 구현했다. 등록번호가 없는 출원 건과 세부 지정상품 포함 기준은 후속 범위다. 상세:
> [`docs/kipris-api-notes.md`](kipris-api-notes.md)의 "알려진 제약" 섹션. 농사로 지역브랜드
> `areaBrandLst` 602건은 출원번호·지역·주요품목이 있어 별도 검증자료로 사용한다. 2026-08-10
> 샘플 3건의 KIPRIS 출원번호 완전일치 조인과 ④ 별도 지표 반영을 확인했다. 다만 이 지역은
> 브랜드 연관 지역이지 출원인 주소가 아니므로 주소 기반 지역 내·외 판정(#11)을 대체하지 않는다.

### ④ 지역 브랜드 분석 → [`04-analyze-brand/`](../04-analyze-brand/)

- 지역별 특산품 상표 출원현황 분석
- 품목별 상표 출원현황 분석
- 지역 내·외 출원인 비중 분석
- 최근 출원 증가 품목 및 신규 브랜드 자동 탐지

> **현재 상태**: ③단계 JSON을 입력으로 지역×품목·지역·품목 집계, 출원번호 중복 제거,
> 상태별·연도별 현황, 최근/직전 동일 기간 증감과 신규 브랜드 예시를 생성하는 분석 CLI가
> 구현됨. 지역 내·외 비중은 검증된 출원인 지역 데이터가 있을 때만 계산하며, 현재는 ③단계의
> 등록원부로 보강된 주소만 비율에 반영하며 미보강은 `unverified`라 대부분 `null`일 수 있다.
> 농사로 지역브랜드 연관성은 출원인 주소와 분리된
> `regionalBrand*` 지표로 집계한다.

### ⑤ 브랜드 공백(Brand Gap) 자동 발굴 → [`05-detect-brand-gap/`](../05-detect-brand-gap/)

- 지역 대표 특산품임에도 상표 출원이 부족한 품목 자동 탐색
- 품목별 상표 활용도가 낮은 지역 자동 식별
- 검증된 통계를 사용한 결정론적 점수로 지역 브랜드 육성 우선순위 후보 도출

> **현재 상태**: ④ 결과를 입력으로 고정 공식의 예시 점수와 근거를 생성한다. 실제 대표성 기준과
> 가중치는 사용자 기준 확정 후 교체하며, 생성형 AI는 점수 계산에 사용하지 않는다.

### ⑥ AI 비즈니스 확장 전략 제안 자동 생성 → [`06-generate-business-strategy/`](../06-generate-business-strategy/)

- ⑥-1에서 분석 결과를 고정 템플릿으로 먼저 요약
  - 예시: "○○군은 대표 특산품 대비 상표 출원이 부족하여 공동브랜드 육성이 필요한 지역으로 분석됨"
  - 예시: "△△시는 지역 외 기업의 출원 비중이 높아 지역 브랜드 보호 전략 검토 필요"
- 필요한 초안만 ⑥-2의 생성형 AI가 개별 검토하고, 원본과 분리된 제안으로 저장
- 지자체·생산자단체 대상 비즈니스 확장 전략 리포트 자동 생성

> **현재 상태**: ⑥-1 고정 템플릿 JSON까지 구현됐다. ⑥-2는 사람이 승인할 검토 대상·감사 필드와
> 모델 운영 기준을 확정한 뒤 별도로 연결하며, AI 제안이 원본 점수나 사실을 자동 변경하지 않는다.

### ⑦ 대시보드 서비스 → [`07-dashboard/`](../07-dashboard/)

- 지역별 브랜드 현황
- 특산품별 상표 출원현황
- 실시간 신규 출원 모니터링
- 브랜드 공백 지도(Brand Gap Map)
- 지역 간 비교 분석
- AI 비즈니스 확장 전략 브리핑 자동 제공

## AX 요소

- 공식 API 기반 결정론적 데이터 수집 자동화
- 규칙 기반 품목 정제 및 애매한 결과의 감사 가능한 수동 검토
- AI 기반 비즈니스 확장 전략 제안 생성
- 반복 업무 자동화 및 분석 시간 단축

## 기대효과

- 정해진 규칙으로 재현 가능한 데이터 처리와 필요한 구간의 사람 검토 분리
- 지역 특산품 브랜드의 실시간 모니터링 체계 구축
- 지자체의 공동브랜드 개발 및 지역브랜드 육성 정책 지원
- 상표 빅데이터의 정책 활용 사례 창출
- 기관의 AI·AX 기반 대표 시범 서비스로 확장 가능
- 지자체 정책 의사결정 지원, 지역 브랜드 육성 대상 발굴, 기관의 AI 활용 우수사례 확보
- 향후 특허·디자인·관광 등으로 확장 가능한 플랫폼 기반 마련

## 개발 방법

- 현재 ①~⑥: Node.js CLI + SQLite, 고정 샘플/모킹 기반 지속 검증
- ⑦ 대시보드: 구현 시 기술 확정(초기 기획안 후보는 Python + Streamlit)
- 상표 Open API 및 공공데이터 연계
- 생성형 AI는 결정론적 처리 이후 필요한 건의 개별 검토에만 분리 적용

## 참고 — 초기 작업 순서 메모 (원문)

기획안 원문 상단에 있던 더 간단한 초안. 위 7단계와 대체로 대응되지만 표현이 다르므로 원문
그대로 남겨둔다.

1. 지역별(16대 광역 226개 기초지자체 목록 기준) 특산품 목록 수집: 농사로 특산물 정보,
   지리적표시권 등록현황, 뉴스 등을 토대로 지역+특산품으로 구분
2. 특산품 목록 자동 정제: 품목 기준
3. 품목-고시명칭 자동 매칭 (13차 기준)
   - 정제 규칙: 35류 이상은 가급적 제외
   - 사과 → 사과나무, 묘목 제외
   - 해당 지역 특산품과 관련있는 고시명칭으로 검색 (예: 안동하회탈)
   - 고시명칭에 없을 경우 비고시명칭으로 검색하게 단순화하여 품목으로 정제
4. 지역+고시명칭 기준 상표 출원정보 자동 업데이트 (출원인 주소+지정상품, 상표 API)
   - 품목 또는 해당 지역 특산품명칭(예: 하회탈)을 상표명으로 사용한 경우?
5. 지역별 상표 출원현황 분석 → 특산품의 상표가 별로 없는 공백지역 파악
6. 품목별 상표 출원현황 분석 → 상표 출원 안된 특산품 파악
