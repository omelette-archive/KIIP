# AI 기반 지역 특산품 브랜드 정책지원 플랫폼 — 프로젝트 기획

출처: `AX 프로젝트.hwpx` (바탕화면 기획안). 저장소의 페이즈(01~07) 구조는 이 문서의 7단계를
그대로 따른다.

## 프로젝트명

**AI 기반 지역 특산품 브랜드 정책지원 플랫폼**

## 추진배경

생성형 AI를 활용한 데이터 수집·정제·분석 자동화 및 지자체 대상 신규 서비스 발굴

## 목표

- 지역 특산품 데이터 자동 수집
- 상표 빅데이터 연계 분석
- AI 기반 비즈니스 확장 전략 제안 자동 생성
- 실시간 대시보드 구축

## 차별성

특허청 상표 빅데이터와 생성형 AI를 결합하여 지역 특산품의 브랜드 활용 수준을 실시간으로
분석하고, 브랜드 공백지역을 자동 도출해 비즈니스 확장 전략을 제안하는 국내 최초 수준의
브랜드 분석 플랫폼 구축.

## 7단계 파이프라인

### ① 지역 특산품 데이터 자동 구축 → [`01-collect-specialties/`](../01-collect-specialties/)

전국 17개 광역 및 226개 기초지자체를 대상으로 특산품 목록 자동 수집.

- 수집 대상: 농사로 특산물 정보, 지리적표시 등록현황, 지자체 홈페이지, 뉴스 기사 및 공공데이터
- 생성형 AI를 활용하여 지역-특산품 관계를 자동 추출 및 통합 DB 구축

### ② 규칙 기반 특산품 표준화 및 별도 AI 검토 → [`02-normalize-items/`](../02-normalize-items/)

- 지역명·품종 설명 제거 등 정해진 규칙으로 특산품 명칭을 1차 정제
- 고시명칭이 `원문`, `신선한 원문`, `미가공 원문` 규칙과 일치할 때만 자동 매핑하고
  부분 일치·복수 분류는 검토 대기열로 분리
- 사과나무·사과묘목 등은 명시적 제외 규칙을 적용
- NICE 상품분류(13판) 자동 매핑 — 분석 목적에 맞는 상품류 중심 분류, **35류 이상은 별도 관리**
- AI는 전체 데이터 자동 처리 대신 검토 대기열의 애매한 품목을 개별 확인하는 용도로 사용

### ③ 지역 특산품 기반 상표정보 자동 수집 → [`03-match-trademarks/`](../03-match-trademarks/)

- 지역명 + 고시명칭 + 품목을 활용하여 상표 Open API 자동 검색
- 상표명뿐 아니라 **지정상품, 상품류, 출원인 주소**를 함께 고려하여 관련 상표 자동 수집
- 신규 출원 정보를 주기적으로 업데이트하여 실시간 데이터베이스 구축

> **현재 상태**: 품목(상품류) 기준 검색·필터는 v1으로 실동작(`03-match-trademarks/`). **출원인
> 주소 기반 지역 매칭은 KIPRIS 상표 검색 API 응답에 해당 필드가 없어 미구현 상태** — 이 기획
> 문서가 요구하는 "출원인 주소 고려"를 만족시키려면 별도 데이터 조인 방식이 필요하다. 상세:
> [`docs/kipris-api-notes.md`](kipris-api-notes.md)의 "알려진 제약" 섹션.

### ④ AI 기반 지역 브랜드 분석 → [`04-analyze-brand/`](../04-analyze-brand/)

- 지역별 특산품 상표 출원현황 분석
- 품목별 상표 출원현황 분석
- 지역 내·외 출원인 비중 분석
- 최근 출원 증가 품목 및 신규 브랜드 자동 탐지

> **현재 상태**: ③단계 JSON을 입력으로 지역×품목·지역·품목 집계, 출원번호 중복 제거,
> 상태별·연도별 현황, 최근/직전 동일 기간 증감과 신규 브랜드 예시를 생성하는 분석 CLI가
> 구현됨. 지역 내·외 비중은 검증된 출원인 지역 데이터가 있을 때만 계산하며, 현재는 ③단계의
> 주소 데이터 미확보로 대부분 `null`이다.

### ⑤ 브랜드 공백(Brand Gap) 자동 발굴 → [`05-detect-brand-gap/`](../05-detect-brand-gap/)

- 지역 대표 특산품임에도 상표 출원이 부족한 품목 자동 탐색
- 품목별 상표 활용도가 낮은 지역 자동 식별
- AI를 활용하여 지역 브랜드 육성 우선순위 후보 도출

### ⑥ AI 비즈니스 확장 전략 제안 자동 생성 → [`06-generate-business-strategy/`](../06-generate-business-strategy/)

- 분석 결과를 생성형 AI가 자동 요약
  - 예시: "○○군은 대표 특산품 대비 상표 출원이 부족하여 공동브랜드 육성이 필요한 지역으로 분석됨"
  - 예시: "△△시는 지역 외 기업의 출원 비중이 높아 지역 브랜드 보호 전략 검토 필요"
- 지자체·생산자단체 대상 비즈니스 확장 전략 리포트 자동 생성

### ⑦ 대시보드 서비스 → [`07-dashboard/`](../07-dashboard/)

- 지역별 브랜드 현황
- 특산품별 상표 출원현황
- 실시간 신규 출원 모니터링
- 브랜드 공백 지도(Brand Gap Map)
- 지역 간 비교 분석
- AI 비즈니스 확장 전략 브리핑 자동 제공

## 참고 — 초기 작업 순서 메모 (원문)

기획안 원문 상단에 있던 더 간단한 초안. 위 7단계와 대체로 대응되지만 표현이 다르므로 원문
그대로 남겨둔다.

1. 지역별(16대 광역 226개 기초지자체 목록 기준) 특산품 목록 수집: 농사로 특산물 정보,
   지리적표시권 등록현황, 뉴스 등을 토대로 지역+특산품으로 구분
2. 특산품 목록 자동 정제: 품목 기준
3. 품목-고시명칭 자동 매칭 (13차 기준)
   - 정제 규칙: 35류 이상은 가급적 제외
   - 사과 → 사과나무, 묘목 제외
   - 해당 지역 특산품과 관련있는 고시명칭으로 검색 (예: 안동하회탈)
   - 고시명칭에 없을 경우 비고시명칭으로 검색하게 단순화하여 품목으로 정제
4. 지역+고시명칭 기준 상표 출원정보 자동 업데이트 (출원인 주소+지정상품, 상표 API)
   - 품목 또는 해당 지역 특산품명칭(예: 하회탈)을 상표명으로 사용한 경우?
5. 지역별 상표 출원현황 분석 → 특산품의 상표가 별로 없는 공백지역 파악
6. 품목별 상표 출원현황 분석 → 상표 출원 안된 특산품 파악
